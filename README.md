# FreeApps by Hamza

Website: https://mhamzam.github.io

Free, ad-free, open-source Android apps, funded by supporters. Plain HTML/CSS: no build step, hosted on GitHub Pages.

## Editing
- **Donation details:** edit `assets/config.js`. Empty values show "Coming soon".
- **Add an app:** copy `apps/tv-remote/` to `apps/<new-app>/`, edit it, and add a row to the "Apps" list in `index.html`.

Push to `main` and the site updates in about a minute.
